# Milestones

## v2.0 Public Choice Engine, MCP & Visual Ledger (Shipped: 2026-11-21)

**Goal:** Transform QualCount into an offline-first visual multiplex partnership operating system featuring ratio-scale Public Choice utility, deterministic two-layer risk auditing, portable workspace folders, cross-workbook entity discovery, local stdio MCP server with 4 production skills, circular tree-and-loop seal branding, and cross-platform desktop binary packaging.

**Shipped Capabilities:**
- **Phase 5: Core Domain Engines, Analytical Dashboard & Impeccable Design System**
  - Normalized Schema v2 with lossless v1 backward migration and Delhi exhibition dataset update.
  - Pure Public Choice utility engine calculating ratio-scale metrics ($R_i, A_i, V_i, C_i, U_i, \eta_i, S_i, \text{PUI}$) without arbitrary scoring.
  - Pure deterministic 6-parameter structural risk engine ($R_1..R_6$) with pinpoint placement/branch attribution and overall risk tier.
  - Impeccable Archival Book & Ledger visual redesign (`#FAF8F4` warm paper, dark ink `#18181B`, emerald `#0F6B38`, amber `#B45309`).
  - Maximized Full-Screen Dashboard (`Cmd/Ctrl+Shift+D`) with inline-editable utility parameters, preset strategy weights, and Two-Layer Risk Assessment Box.
  - Native RFC-4180 CSV export bundle and 4-sheet formatted Excel (`.xlsx`) export; 3-door import modal (file upload, local MCP agent, dynamic Web AI conversion prompts).
- **Phase 6: Portable Workspace Storage, Landing Page & Cross-Workbook Autocomplete**
  - Portable Workspace Folder storage structure (`workspace.json`, `entities.json`, `workbooks/*.json`, `.snapshots/`) preventing SQLite WAL corruption over cloud mirrors.
  - Editorial Landing Page (Cover & Table of Contents) with workspace switcher, `[Local]` and `[Google Drive]` badges, workbook KPIs, and Overview Macro-Map.
  - Persistent Legacy Menu Bar (`File`, `View`, `Tools`) with keyboard shortcuts (`Cmd/Ctrl+N`, `Cmd/Ctrl+O`, `Cmd/Ctrl+S`, `Cmd/Ctrl+B`), sibling Book Index sidebar, and Google Drive connector modal.
  - Real-time cross-workbook entity fuzzy autocomplete with yellow referral bridge detection and non-destructive pending lead pull.
- **Phase 7: Local Stdio MCP Server & Production Agent Skills**
  - Production `@modelcontextprotocol/sdk` server (`packages/mcp-server/`) exposing 17 zod-validated tools and 4 resources sharing pure TypeScript domain engines.
  - Pre-write safety protocol with 20-snapshot rolling backup, atomic temp-file writes, and in-app `Undo Agent Change` hot-reload action.
  - 4 production agent skills installed across `.agent/skills/`, `.claude/skills/`, and `.cursor/skills/`: `QualCount-partnership-graph-operator`, `QualCount-public-choice-utility-analyst`, `QualCount-two-layer-risk-auditor`, and `QualCount-spreadsheet-to-workflow-mapper`.
- **Milestone Polish, Branding & Native Windows Packaging**
  - Circular emblem logo: directed multiplex tree diagram encircled by an orbital loop with "QUALICOUNT" typography beneath.
  - Multi-resolution Windows app icons (`icon.ico`, `icon.png`, `32x32.png`, `128x128.png`, `Square...png`) and web favicons.
  - Native Windows single-file setup installer (`QualCount-Setup.exe`) and standalone desktop binary (`QualCount.exe`) built via Tauri v2.
