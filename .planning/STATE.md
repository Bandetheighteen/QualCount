## Accumulated Context

### Decisions

Decisions are logged in PROJECT.md Key Decisions table.
Key v2.0 architectural decisions:
- Portable JSON Workspace Folders over single-file SQLite: Prevents cloud-sync WAL corruption, supports human readability, and enables local MCP direct access.
- Ratio-scale Public Choice Theory over arbitrary points: Formalizes Buchanan-Tullock decision costs, Olson selective incentives, Niskanen utility, Ostrom durability, and Centola-Macy screening.
- Two-Layer Risk Engine (Zero ML): Deterministic 6-parameter topological matrix combined with persistent agentic audit briefing.
- Editorial "Book & Ledger" UI via Impeccable: Warm archival paper (`#FAF8F4`) and high-contrast ink lines (`#0F6B38`, `#18181B`, `#B45309`) replacing generic AI dark glass.
- Local stdio MCP Server (17 tools) + 4 Production Agent Skills: Gives external AI tools direct, safe operational access.
- 3-Door Spreadsheet Import: Handles structured CSV/XLSX, local MCP agents, and dynamic copyable Web AI prompts.
