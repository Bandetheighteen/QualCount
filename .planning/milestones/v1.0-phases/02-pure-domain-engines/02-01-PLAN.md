# Plan 02-01: Pure Quantitative 7-Metric Engine

## Objective
Implement `src/engine/metrics.ts` as a pure TypeScript module computing all 7 topology-derived quantitative indicators, node-level multi-thread in-degree, BFS downstream reach, and bridge concentration risk with zero subjective scoring and zero DOM/React dependencies.

    Create src/engine/metrics.ts:
    1. Define metric result interfaces:
       - `FundingMetrics`: `{ securedPct: number, pendingPct: number, declinedCount: number, securedInr: number }`
       - `DirectRelationshipMetrics`: `{ confirmedCount: number, pendingCount: number, declinedCount: number, confirmationRatePct: number }`
       - `YellowBridgeMetrics`: `{ confirmedCount: number, pendingCount: number, declinedCount: number }`
       - `OwnedConversionMetrics`: `{ referredNodeCount: number, convertedNodeCount: number, conversionRatePct: number }`
       - `MultiThreadMetrics`: `{ doubleThreadCount: number, tripleThreadCount: number, quadPlusThreadCount: number, triplePlusNames: string[] }`
       - `TopAmplifierMetrics`: `{ entityId: string | null, entityName: string, directOutDegree: number, downstreamReachCount: number }`
       - `BridgeConcentrationMetrics`: `{ bridgeEntityName: string, concentrationPct: number, unreachableCount: number }`
       - `WorkspaceTopologyMetrics`: root object combining all 7 metric categories.
    2. Implement `getNodeYellowInDegree(placementId: string, branches: Record<string, Branch>): number`:
       - Count incoming yellow branches with `status === 'tick'`.
    3. Implement `getNodeAmplifierReach(placementId: string, placements: Record<string, Placement>, branches: Record<string, Branch>): number`:
       - Run BFS along outgoing ticked yellow branches discovering unique downstream placements (excluding root NGO and self).
    4. Implement `computeTopologyMetrics(state: WorkspaceState, activeWorkbookId?: string): WorkspaceTopologyMetrics`:
       - Filter placements and branches by active workbook ID.
       - Calculate funding: sum `valuePct` of ticked green branches, pending green branches, and count declined green branches. Calculate INR from `workbook.targetBudgetInr`.
       - Calculate direct white relationships from root NGO: counts of tick, pending, cross, and confirmation rate %.
       - Calculate confirmed yellow bridges: counts of tick, pending, cross.
       - Calculate owned conversions: non-root placements with >= 1 incoming ticked yellow branch, and how many also hold >= 1 incoming ticked white branch from root NGO.
       - Calculate multi-thread targets: group by incoming ticked yellow in-degree (2, 3, 4+), and list names of triple-thread and above.
       - Calculate top amplifier reach via BFS for every non-root partner.
       - Calculate bridge concentration risk %: discover total unique indirect reach from root NGO via ticked yellow paths of length >= 2 ($R_{\text{total}}$), remove highest-reach bridge $b$, and measure lost reach percentage.
    5. Ensure zero imports from `react`, `window`, `document`, or `localStorage`.
