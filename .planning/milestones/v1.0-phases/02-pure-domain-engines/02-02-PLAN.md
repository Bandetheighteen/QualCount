# Plan 02-02: Pure Parallel Bezier Curve Offset Engine

## Objective
Implement `src/engine/parallelEdges.ts` as a pure geometric TypeScript module that detects parallel multiplex branches connecting the same placement pair, calculates symmetric lateral Bezier curve offsets, and evaluates coordinates for mid-line M% pills ($t = 0.5$) and end-of-line Tick/Cross buttons ($t = 0.8$) so parallel lines, pills, and buttons never overlap.

    Create src/engine/parallelEdges.ts:
    1. Define interfaces:
       - `EdgeEndpoint`: `{ x: number, y: number }`
       - `ParallelBranchGeometry`: `{ path: string, labelX: number, labelY: number, buttonX: number, buttonY: number, offsetDistance: number }`
    2. Implement `groupParallelBranches(branches: Branch[]): Map<string, Branch[]>`:
       - Group branches by canonical undirected placement key: `[min(sourcePlacementId, targetPlacementId), max(sourcePlacementId, targetPlacementId)].join('---')`.
    3. Implement `computeParallelBezierCurve(source: EdgeEndpoint, target: EdgeEndpoint, index: number, total: number, spacing: number = 36): ParallelBranchGeometry`:
       - Calculate displacement offset: `d = total === 1 ? 0 : (index - (total - 1) / 2) * spacing`.
       - Compute direction vector from source to target: $V = (target.x - source.x, target.y - source.y)$.
       - Compute length $L = \sqrt{V_x^2 + V_y^2}$.
       - If $L < 1$, fallback to straight line.
       - Compute normal unit vector $N = (-V_y / L, V_x / L)$.
       - Since canvas is bottom-to-top (source at top, target at bottom), control points:
         - Baseline vertical curvature: $\Delta y = target.y - source.y$.
         - $CP_1 = (source.x + N_x \cdot d, source.y + \Delta y \cdot 0.35 + N_y \cdot d)$
         - $CP_2 = (target.x + N_x \cdot d, target.y - \Delta y \cdot 0.35 + N_y \cdot d)$
       - Generate SVG path string: `M ${source.x} ${source.y} C ${CP1.x} ${CP1.y}, ${CP2.x} ${CP2.y}, ${target.x} ${target.y}`.
       - Evaluate cubic Bezier at $t = 0.5$ for mid-line label/pill: $(1-t)^3 P_0 + 3(1-t)^2 t P_1 + 3(1-t) t^2 P_2 + t^3 P_3$.
       - Evaluate cubic Bezier at $t = 0.8$ for end-of-line Tick/Cross buttons.
    4. Ensure zero imports from `react`, `window`, `document`, or `localStorage`.
