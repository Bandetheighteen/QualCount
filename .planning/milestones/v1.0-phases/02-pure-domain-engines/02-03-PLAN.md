# Plan 02-03: Pure Local Rectangular Anti-Overlap Engine

## Objective
Implement `src/engine/overlap.ts` as a pure geometric TypeScript module that detects bounding-box collisions among rectangular node cards with a 24px safety margin, keeping the user's dragged card strictly anchored while nudging only colliding neighbor cards apart by minimum displacement.

  <action>
    Create src/engine/overlap.ts:
    1. Define interfaces:
       - `BoundingBox`: `{ id: string, x: number, y: number, width: number, height: number, isFixed?: boolean }`
       - `CollisionResolutionResult`: `{ positions: Record<string, { x: number, y: number }>, movedNodeIds: string[] }`
    2. Implement `checkAABBCollision(boxA: BoundingBox, boxB: BoundingBox, margin: number = 24): { collides: boolean, overlapX: number, overlapY: number }`:
       - Box bounds: $left = x - margin$, $right = x + width + margin$, $top = y - margin$, $bottom = y + height + margin$.
       - Compute horizontal overlap: $overlapX = \min(A.right, B.right) - \max(A.left, B.left)$.
       - Compute vertical overlap: $overlapY = \min(A.bottom, B.bottom) - \max(A.top, B.top)$.
       - Collides if $overlapX > 0$ and $overlapY > 0$.
    3. Implement `resolveLocalCollisions(placements: Record<string, Placement>, anchoredPlacementId?: string, margin: number = 24, maxIterations: number = 25): CollisionResolutionResult`:
       - Initialize working bounding boxes from `placements`.
       - Mark `anchoredPlacementId` as `isFixed: true` (its $(x, y)$ coordinates must never be altered).
       - Iterate up to `maxIterations`:
         - Find all colliding pairs $(A, B)$.
         - If zero collisions, break early.
         - For each colliding pair, resolve along the axis of minimum penetration ($\min(overlapX, overlapY)$):
           - If $A$ is fixed, shift $B$ by the full overlap amount away from $A$.
           - If $B$ is fixed, shift $A$ by the full overlap amount away from $B$.
           - If neither is fixed, shift both by $overlap / 2$ in opposite directions.
       - Return updated coordinates `{ positions, movedNodeIds }`.
    4. Ensure zero imports from `react`, `window`, `document`, or `localStorage`.
  </action>
