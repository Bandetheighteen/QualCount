# Plan 02-04: Pure Bottom-to-Top ELK Layout Engine

## Objective
Implement `src/engine/layout.ts` using `elkjs` to compute a discrete bottom-to-top (`elk.direction: "UP"`) Sugiyama layered hierarchical layout with strict read-only topology preservation and graceful handling of isolated / zero-degree nodes.

  <action>
    Create src/engine/layout.ts:
    1. Import ELK from 'elkjs/lib/elk.bundled.js'.
    2. Instantiate ELK layout engine singleton.
    3. Define layout options:
       - 'elk.algorithm': 'layered'
       - 'elk.direction': 'UP'
       - 'elk.edgeRouting': 'SPLINES'
       - 'elk.spacing.nodeNode': '72'
       - 'elk.layered.spacing.nodeNodeBetweenLayers': '125'
       - 'elk.layered.crossingMinimization.strategy': 'LAYER_SWEEP'
       - 'elk.layered.nodePlacement.strategy': 'NETWORK_SIMPLEX'
    4. Implement `computeHierarchicalLayout(placements: Record<string, Placement>, branches: Record<string, Branch>, activeWorkbookId?: string): Promise<Record<string, { x: number, y: number }>>`:
       - Filter placements and branches by `activeWorkbookId`.
       - Identify connected placements vs. isolated placements (placements with zero incoming/outgoing branches).
       - For connected placements:
         - Construct ELK graph definition with `children` containing `id`, `width: p.width || 190`, `height: p.height || 76`.
         - Add `edges` containing `id: branchId`, `sources: [b.sourcePlacementId]`, `targets: [b.targetPlacementId]`.
         - Invoke `elk.layout(elkGraph)`.
         - Map computed `x` and `y` coordinates back to placement IDs.
       - For isolated placements:
         - Calculate bounding bounds of the laid-out graph.
         - Position isolated nodes neatly in a baseline staging rack below Tier 0 (e.g. $y = maxY + 150$, spaced horizontally by 220px).
       - Ensure topology is strictly read-only: zero mutations to `branches` or `placements`.
       - Return a plain dictionary mapping `Record<string, { x: number, y: number }>`.
    5. Ensure zero imports from `react`, `window`, `document`, or `localStorage`.
