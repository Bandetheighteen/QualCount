# Plan 03-01: Zustand Workspace Store (`src/store/useWorkspaceStore.ts`)

## Goal
Implement the central reactive Zustand store that manages normalized workspace state, bridges storage persistence via `WorkspaceRepository`, recomputes live metrics and `yellowInDegree` on graph mutations, and generates React Flow node/edge structures with parallel curve indices.

## Detailed Steps

1. **Define Store State & Interface**:
   ```typescript
   export interface WorkspaceStoreState {
     workspace: WorkspaceState | null;
     activeWorkbookId: string | null;
     selectedPlacementId: string | null;
     selectedBranchId: string | null;
     showDeclined: boolean;
     isLayoutRunning: boolean;
     metrics: TopologyMetrics | null;
     yellowInDegrees: Record<string, number>;
     
     // Actions
     init: () => Promise<void>;
     selectPlacement: (id: string | null) => void;
     selectBranch: (id: string | null) => void;
     toggleShowDeclined: () => void;
     onNodeDragStop: (placementId: string, position: { x: number; y: number }) => Promise<void>;
     setBranchStatus: (branchId: string, status: BranchStatus) => Promise<void>;
     tidyUpLayout: () => Promise<void>;
     resetToDelhiSeed: () => Promise<void>;
     
     // Getters for React Flow
     getFlowNodes: () => Node[];
     getFlowEdges: () => Edge[];
   }
   ```

2. **Implement React Flow Generators**:
   - `getFlowNodes`:
     - Maps each placement to a React Flow `Node` with `id: placement.placementId`, `type: 'orgNode'`, `position: { x: placement.x, y: placement.y }`.
     - Data payload includes:
       - `entity`: corresponding `Entity` record.
       - `placement`: the `Placement` record.
       - `yellowInDegree`: current incoming confirmed yellow bridge count.
       - `selected`: `placement.placementId === selectedPlacementId`.
   - `getFlowEdges`:
     - Groups active workbook branches using `groupParallelBranches(branches)`.
     - Determines for each branch its 0-based `index` in the group, the `total` parallel branches, and `isReverse` flag.
     - Maps each branch to a React Flow `Edge` with `id: branch.branchId`, `source: branch.sourcePlacementId`, `target: branch.targetPlacementId`, `type: 'multiplexEdge'`.
     - If `showDeclined === false` and `branch.status === 'cross'`, the edge is excluded from the returned array.
     - Data payload includes: `{ branch, index, total, isReverse, selected: branch.branchId === selectedBranchId }`.

3. **Implement Collision & Drag Stop Handler**:
   - Updates the dragged placement to the exact drop position `(position.x, position.y)`.
   - Passes all current placements to `resolveLocalCollisions(placements, placementId, 24)`.
   - Updates any neighbor placements that were nudged.
   - Commits the updated workspace state to `getWorkspaceRepository().saveWorkspace(...)`.

4. **Implement Status Toggle & Live Recomputation**:
   - `setBranchStatus(branchId, status)`:
     - Updates target branch `status` and `updatedAt`.
     - Recomputes `metrics` via `computeTopologyMetrics(placements, branches)`.
     - Recomputes `yellowInDegrees` for all placements via `getNodeYellowInDegree`.
     - Commits updated workspace to repository asynchronously.

5. **Implement Tidy Up Handler**:
   - Calls `computeHierarchicalLayout(placements, branches)`.
   - Updates placements with newly computed coordinates.
   - Commits updated workspace to repository.
