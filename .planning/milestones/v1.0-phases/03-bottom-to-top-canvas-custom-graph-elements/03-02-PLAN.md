# Plan 03-02: Custom OrgNode Component (`src/components/canvas/OrgNode.tsx`)

## Goal
Create the custom React Flow node component `OrgNode.tsx` featuring inverted connection handles (source Top, target Bottom), sector category pills, a root NGO indicator, live multi-thread badges, and hover statistics.

## Context
- **Requirements**: CANV-02
- **Schema**: `Entity`, `Placement` from [src/types/schema.ts](file:///c:/Users/shoun/Desktop/Dokumen/QualCount/src/types/schema.ts)
- **Design Specifications**:
  - Inverted handles: `<Handle type="source" position={Position.Top} />` and `<Handle type="target" position={Position.Bottom} />`
  - Multi-Thread Badge thresholds:
    - `yellowInDegree === 2`: `"2-Thread"`
    - `yellowInDegree === 3`: `"Triple-Thread (3)"` (glowing amber)
    - `yellowInDegree >= 4`: `"Quad-Thread ({yellowInDegree})"` (bright gold)
    - `yellowInDegree < 2`: none

## Detailed Steps

1. **Category Styling Map**:
   Map `EntityCategory` to Tailwind classes:
   - `ngo`: `bg-sky-500/15 text-sky-300 border-sky-500/30`
   - `csr`: `bg-emerald-500/15 text-emerald-300 border-emerald-500/30`
   - `government`: `bg-amber-500/15 text-amber-300 border-amber-500/30`
   - `institution`: `bg-purple-500/15 text-purple-300 border-purple-500/30`
   - `community`: `bg-rose-500/15 text-rose-300 border-rose-500/30`
   - `other`: `bg-slate-500/15 text-slate-300 border-slate-500/30`

2. **Multi-Thread Badge Subcomponent**:
   - Helper function or JSX determining badge text and glow styling based on `yellowInDegree`.
   - Incorporates Lucide icon (e.g. `Network` or `GitFork`) to emphasize multiplex bridges.

3. **Inverted Handle Registration**:
   - Source handle: Top center (`Position.Top`) with low-opacity styling that highlights on hover.
   - Target handle: Bottom center (`Position.Bottom`).

4. **Root NGO Marker**:
   - If `placement.isRootNgo` is true, render a crown/star icon or `"ROOT NGO"` badge, with subtle amber/gold card border illumination (`border-amber-500/50 shadow-[0_0_15px_rgba(245,158,11,0.15)]`).

5. **Hover Stats Tooltip**:
   - Card displays an expandable or hover mini-summary showing incoming/outgoing connection indicators.
