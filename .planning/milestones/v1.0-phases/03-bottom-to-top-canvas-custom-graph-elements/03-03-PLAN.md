# Plan 03-03: Custom MultiplexEdge Component (`src/components/canvas/MultiplexEdge.tsx`)

## Goal
Implement the custom React Flow edge component `MultiplexEdge.tsx` that computes lateral parallel Bezier curve paths, renders the strict color/dash/glow/gray styling matrix across branch types and statuses, and displays mid-line M% pills and end-of-line Tick/Cross action buttons via `EdgeLabelRenderer` with complete event shielding.

## Context
- **Requirements**: CANV-03, CANV-04
- **Engine**: `computeParallelBezierCurve` from [src/engine/parallelEdges.ts](file:///c:/Users/shoun/Desktop/Dokumen/QualCount/src/engine/parallelEdges.ts)
- **Store**: `useWorkspaceStore` from [src/store/useWorkspaceStore.ts](file:///c:/Users/shoun/Desktop/Dokumen/QualCount/src/store/useWorkspaceStore.ts)
- **Visual Matrix**:
  - `green` (funding): emerald-500 (pending dashed), emerald-400 glowing (tick solid), gray (cross)
  - `white` (relationship): slate-300 (pending dashed), white glowing (tick solid), gray (cross)
  - `yellow` (bridge): amber-500 (pending dashed), amber-400 glowing (tick solid), gray (cross)

## Detailed Steps

1. **Endpoint & Bezier Math Calculation**:
   - Extract source and target coordinates from `EdgeProps`: `{ sourceX, sourceY, targetX, targetY }`.
   - Extract `{ branch, index, total, isReverse }` from `data`.
   - Call `computeParallelBezierCurve({ x: sourceX, y: sourceY }, { x: targetX, y: targetY }, index, total, 36, isReverse)`.
   - Obtain `{ path, labelX, labelY, buttonX, buttonY }`.

2. **SVG Path Rendering**:
   - Render `<BaseEdge path={path} style={edgeStyle} />`.
   - Configure SVG `stroke`, `strokeWidth`, `strokeDasharray`, and inline SVG filter / glow according to `type` and `status`.

3. **EdgeLabelRenderer Action Overlay**:
   - Wrap mid-line pill and action buttons in `<EdgeLabelRenderer>`.
   - Mid-line pill:
     - Render at `(labelX, labelY)` using CSS translate `translate(-50%, -50%)`.
     - If `branch.type === 'green'` and `branch.valuePct !== undefined`, render `M{valuePct}%`.
     - Container must have `nodrag nopan pointer-events-auto` and `onClick={(e) => e.stopPropagation()}`.
   - Action Buttons Container:
     - Render at `(buttonX, buttonY)` using CSS translate `translate(-50%, -50%)`.
     - Container class: `nodrag nopan pointer-events-auto flex items-center gap-1 bg-slate-900/90 p-1 rounded-full border border-slate-700/80 shadow-md backdrop-blur-sm`.
     - Both container and buttons have `onPointerDown={(e) => e.stopPropagation()}` and `onClick={(e) => e.stopPropagation()}`.
   - **Tick Button**:
     - Lucide `Check` icon.
     - Toggles between `tick` and `pending`: `setBranchStatus(branch.branchId, branch.status === 'tick' ? 'pending' : 'tick')`.
     - Active styling: `bg-emerald-600 text-white border-emerald-400 shadow-[0_0_8px_rgba(16,185,129,0.5)]`.
   - **Cross Button**:
     - Lucide `X` icon.
     - Toggles between `cross` and `pending`: `setBranchStatus(branch.branchId, branch.status === 'cross' ? 'pending' : 'cross')`.
     - Active styling: `bg-rose-600 text-white border-rose-400 shadow-[0_0_8px_rgba(244,63,94,0.5)]`.
