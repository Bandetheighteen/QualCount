# Plan 04-01: Live Top Metrics Strip (`src/components/metrics/MetricsStrip.tsx`)

## Goal
Implement the permanently visible top metrics dashboard `MetricsStrip.tsx` that displays all 7 live quantitative topology metrics above the canvas, dynamically updating on every graph edit without subjective scoring.

## Context
- **Requirements**: UI-01
- **Metrics Engine**: `src/engine/metrics.ts`
- **Store**: `src/store/useWorkspaceStore.ts`
- **Metrics Covered**:
  1. Funding Secured (`M%` vs Target Budget INR, pending %, progress bar)
  2. Direct White Relationships (confirmed, pending, declined, confirmation rate %)
  3. Confirmed Yellow Bridges (count of active network bridges)
  4. Owned Conversions (`converted / referred` count and conversion rate %)
  5. Multi-Thread Targets (2x, 3x, 4x+ pills with names)
  6. Top Amplifier (partner name, direct out-degree, unique downstream reach)
  7. Bridge Concentration Risk (partner name, concentration %, red alert if $> 30\%$)

## Detailed Steps

1. **Component Scaffold & Layout**:
   - Create `src/components/metrics/MetricsStrip.tsx`.
   - Layout: Fixed or sticky top bar spanning viewport width (`bg-slate-900/95 border-b border-slate-800 backdrop-blur-md px-4 py-2.5 z-20`).
   - Grid or flex wrap with 7 compact metric cards.

2. **Metric Card 1: Funding Secured**:
   - Visual dual-color progress bar: solid emerald for confirmed `securedPct`, striped/amber for `pendingPct`.
   - Text display: `M{securedPct}%` + absolute INR (formatted via `Intl.NumberFormat('en-IN')`).
   - Display target budget INR (from active workbook).

3. **Metric Card 2: Direct White Relationships**:
   - Displays confirmed tick count (white text), pending count (slate text), declined cross count (slate-500 text).
   - Confirmation rate percentage pill.

4. **Metric Card 3: Confirmed Yellow Bridges**:
   - Network bridge icon (`GitFork` / `Network` from Lucide).
   - Total count of verified active yellow bridges.

5. **Metric Card 4: Owned Conversions**:
   - Ratio: `converted / referred` (e.g. `1 / 6 referred`).
   - Conversion rate percentage pill.

6. **Metric Card 5: Multi-Thread Targets**:
   - Display pills for:
     - `2x`: count of 2-Thread targets (amber).
     - `3x`: count of 3-Thread targets (glowing amber).
     - `4x+`: count of 4+-Thread targets (gold).
   - Names of targets with $\ge 3$ threads (e.g. `Sports Dev Office`).

7. **Metric Card 6: Top Amplifier**:
   - Partner name with maximum downstream reach.
   - Sub-stats: `Direct: {outDegree}` and `Total Reach: {reach}`.

8. **Metric Card 7: Bridge Concentration Risk**:
   - Single point of failure bridge entity name.
   - Risk percentage (`concentrationPct%`).
   - Conditional styling: If `concentrationPct > 30`, apply danger badge: `border-rose-500/40 bg-rose-500/10 text-rose-300 font-semibold shadow-[0_0_10px_rgba(244,63,94,0.2)]`.
