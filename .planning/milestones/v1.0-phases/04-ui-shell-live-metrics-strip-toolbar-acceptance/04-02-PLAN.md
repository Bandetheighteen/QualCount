# Plan 04-02: Compact Action Toolbar with Entity Autocomplete Deduplication (`src/components/toolbar/ActionToolbar.tsx`)

## Goal
Implement the Action Toolbar with modal dialogs for node creation (with live entity autocomplete deduplication), branch connection (with parallel line support and self-loop blocking), hierarchical Tidy Up, declined paths toggle, and JSON export/import/reset actions via `WorkspaceRepository`.

## Context
- **Requirements**: UI-02
- **Store**: `src/store/useWorkspaceStore.ts`
- **Storage**: `WorkspaceRepository` via `src/storage/index.ts`
- **Engines**: `resolveLocalCollisions` (overlap), `computeHierarchicalLayout` (layout)

## Detailed Steps

1. **Extend Workspace Store with Creation & Storage Actions**:
   - Add `addNode(name: string, category: EntityCategory, globalNotes?: string)`:
     - Searches `workspace.entities` for an existing entity with matching name (case-insensitive trim).
     - If found: reuses existing `entityId` and copies category.
     - If not found: generates new `entityId` and creates new `Entity` record.
     - Computes initial coordinates for new placement (e.g. horizontal center, vertical tier position).
     - Runs `resolveLocalCollisions()` to ensure the new node does not overlap any existing card.
     - Inserts `Placement`, updates state, selects the new placement, and saves to repository.
   - Add `addBranch(sourcePlacementId, targetPlacementId, type, status, valuePct, note)`:
     - Validates `sourcePlacementId !== targetPlacementId` (blocks self-loops).
     - Creates new `Branch` record with generated UUID and current timestamp.
     - Inserts into `workspace.branches`, recalculates metrics and yellow in-degrees, selects the branch, and saves to repository.
   - Add `exportWorkspace()` and `importWorkspace()`:
     - Proxies to `WorkspaceRepository.exportWorkspaceFile()` and `importWorkspaceFile()`.
     - On import: updates workspace state, triggers layout recalculation, and updates metrics.

2. **Action Toolbar Component (`src/components/toolbar/ActionToolbar.tsx`)**:
   - Renders a compact floating or docked bar below the metrics strip (`bg-slate-900/90 border border-slate-700/80 rounded-xl px-3 py-1.5 shadow-xl backdrop-blur-md flex items-center gap-3`).
   - Action buttons:
     - `Add Node` (triggers modal)
     - `Connect Branch` (triggers modal)
     - `Tidy Up (Bottom-to-Top)` (with `Wand2` / `Sparkles` icon)
     - `Show Declined (Gray) Paths` toggle checkbox with label
     - Vertical divider
     - `Export JSON` (calls `exportWorkspace()`)
     - `Import JSON` (calls `importWorkspace()`)
     - `Reset Demo` (with confirmation alert)

3. **Add Node Modal (`src/components/toolbar/AddNodeModal.tsx`)**:
   - Organization Name input with dropdown autocomplete:
     - Filters `state.entities` matching user keystrokes.
     - Clicking an item auto-populates the input and locks/selects its category.
     - Shows badge: `"Existing Partner (Reusing ID)"` vs `"New Partner"`.
   - Category dropdown (`csr`, `government`, `institution`, `community`, `other`).
   - Notes input (optional).
   - "Add Node" button that closes the modal on submit.

4. **Connect Branch Modal (`src/components/toolbar/ConnectBranchModal.tsx`)**:
   - Source placement dropdown and Target placement dropdown (labeled with entity names).
   - Line Type selector:
     - Green: `Financial / CSR Funding`
     - White: `Direct Working Relationship`
     - Yellow: `Network Bridge / Referral`
   - Status selector: `Pending (Outreach)`, `Tick (Confirmed / Verified)`, `Cross (Declined)`.
   - Conditional inputs:
     - If Green: `M%` numeric input (1% to 100%).
     - If White or Yellow: `Note` text input.
   - Submit button disabled if `source === target`.
