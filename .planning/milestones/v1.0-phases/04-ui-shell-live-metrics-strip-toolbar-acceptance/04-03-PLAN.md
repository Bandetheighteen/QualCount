# Plan 04-03: Collapsible Context Inspector Drawer (`src/components/inspector/InspectorDrawer.tsx`)

## Goal
Implement the Context Inspector Drawer that displays deep details and editable fields for the currently selected Node or Branch, supporting in-place property editing, branch deletion, and placement removal (protected against Root NGO deletion).

## Context
- **Requirements**: UI-03
- **Store**: `src/store/useWorkspaceStore.ts`
- **Schema**: `Entity`, `Placement`, `Branch` from [src/types/schema.ts](file:///c:/Users/shoun/Desktop/Dokumen/QualCount/src/types/schema.ts)

## Detailed Steps

1. **Extend Workspace Store with Editing & Deletion Actions**:
   - `updateEntity(entityId: string, updates: Partial<Entity>)`: Updates entity name, category, or globalNotes; persists to repository.
   - `updateBranch(branchId: string, updates: Partial<Branch>)`: Updates branch type, status, valuePct, or note; recalculates topology metrics and yellow in-degrees; persists to repository.
   - `deleteBranch(branchId: string)`: Removes branch from `workspace.branches`; deselects; recalculates metrics; persists.
   - `removePlacement(placementId: string)`:
     - Throws/blocks if `placement.isRootNgo === true`.
     - Removes the placement from `workspace.placements`.
     - Cascades: deletes all branches where `sourcePlacementId === placementId || targetPlacementId === placementId`.
     - Deselects; recalculates metrics; persists to repository.

2. **Inspector Drawer Shell (`src/components/inspector/InspectorDrawer.tsx`)**:
   - Sliding panel or absolute drawer positioned on the right side of the canvas (`w-88 absolute right-4 top-16 bottom-4 bg-slate-900/95 border border-slate-700/80 rounded-2xl shadow-2xl backdrop-blur-md flex flex-col z-20 overflow-hidden transition-all duration-200`).
   - If neither a placement nor a branch is selected, drawer is collapsed or displays a subtle helper card: *"Click any partner card or connection line to inspect details."*
   - Close button calling `clearSelection()`.

3. **Node Inspector View**:
   - Display Entity Name input (editable on change or blur).
   - Category selector dropdown.
   - Root NGO badge or category pill indicator.
   - Global Notes textarea.
   - Topology Stats:
     - Confirmed yellow in-degree with dynamic multi-thread badge preview.
     - Downstream unique reach count via BFS.
   - Attached Branches summary:
     - Lists all incoming and outgoing branches with status and type pills.
     - Clicking an attached branch selects it in the inspector.
   - Danger Action:
     - "Remove Organization from Workbook" button.
     - Disabled with tooltip if `isRootNgo === true` ("Root NGO cannot be removed").

4. **Branch Inspector View**:
   - Source Entity $\to$ Target Entity header with line type indicator.
   - Status selector with interactive pill buttons: `Pending`, `Tick (Confirmed)`, `Cross (Declined)`.
   - Branch Type dropdown (`Funding (Green)`, `Relationship (White)`, `Bridge (Yellow)`).
   - Conditional `M%` input if branch is Green.
   - Note textarea for qualitative details and referral context.
   - Danger Action:
     - "Delete Branch" button.
