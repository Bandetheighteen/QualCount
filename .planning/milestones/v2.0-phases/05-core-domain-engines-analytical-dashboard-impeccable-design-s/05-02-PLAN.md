## Objective
Implement pure TypeScript calculation engines for Public Choice Theory utility maximization (`src/engine/utility.ts`) and the 6-parameter deterministic Layer 1 structural risk model (`src/engine/risk.ts`) with zero DOM/React/storage dependencies.

## Requirements
- `ENG-05`: Pure TypeScript Public Choice utility engine computing $O_i, S_i, R_i, A_i, V_i, C_i, U_i, \eta_i, \text{PUI}$, and 4-part additive audit decomposition.
