# Plan 05-04: Maximized Full-Screen Dashboard & Two-Layer Risk Box

## Objective
Build the Maximized Full-Screen Analytical Dashboard (`Cmd/Ctrl + Shift + D`) featuring the 4-section editorial book ledger, live Public Choice utility editing (touch steppers, selective incentive tags, co-ownership checkboxes, strategy presets), and the Two-Layer Risk Assessment Box.

## Requirements
- `DASH-01`: Maximized full-screen dashboard toggle (`Cmd/Ctrl + Shift + D` or button) over active workbook without losing canvas pan/zoom state.
- `DASH-02`: Public Choice Utility Ledger table with inline editable cells (outreach touches, selective incentives, co-ownership checks, strategy presets).
- `DASH-03`: Two-Layer Risk Assessment Box rendering Layer 1 deterministic matrix (with canvas jump-highlighting) alongside Layer 2 persistent agent audit briefing.
