# Plan 05-05: Native CSV/Excel Export & 3-Door Import Pipeline

## Objective
Implement native RFC-4180 UTF-8 BOM CSV and Excel export, alongside the unified Three-Door Spreadsheet Import modal (native template importer, MCP agent instructions, and dynamic Web AI conversion prompt bridge).

## Requirements
- `IO-01`: Native instant export generating RFC-4180 UTF-8 BOM CSV bundles (`_nodes.csv`, `_branches.csv`) and 4-tab Excel workbook (`.xlsx`).
- `IO-02`: Unified Three-Door Import modal (Door 1 structured template, Door 2 local MCP instructions, Door 3 dynamic "Copy Web AI Conversion Prompt" bridge).
