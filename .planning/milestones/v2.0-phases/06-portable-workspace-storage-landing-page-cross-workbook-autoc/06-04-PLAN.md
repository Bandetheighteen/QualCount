# Plan 06-04: Cross-Workbook Entity Detection & One-Click Import Engine

## Objective
Implement live 3-character cross-workbook entity detection ("collectorate" lookup) against current `entities.json` and the cross-workspace index, with one-click entity import and an optional proven-bridge pull to import referral leads as dashed pending yellow branches without false confirmations.

## Requirements
- `MEM-01`: Live 3-character fuzzy entity autocomplete against `entities.json` and device-local `recent-entities-index.json`.
- `MEM-02`: One-click entity import with self-contained origin metadata (`importedFrom`), with optional toggle to pull confirmed downstream referral leads as dashed pending yellow branches.
