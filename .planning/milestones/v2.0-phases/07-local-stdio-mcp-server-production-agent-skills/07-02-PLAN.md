# Plan 07-02: 17 Zod-Validated MCP Tools & 4 Resources Implementation

## Objective
Implement all 17 Zod-validated Model Context Protocol tools and 4 URI resources defined in Section 8 of the Master Architecture Specification, connecting them to QualCount's pure TypeScript calculation engines (`utility.ts`, `risk.ts`, `layout.ts`, `entityIndex.ts`) and the atomic `McpWorkspaceStorage`.

## Requirements Covered
- `MCP-01`: Dedicated stdio MCP server package (`packages/mcp-server/`) built with `@modelcontextprotocol/sdk` exposing all 17 zod-validated tools across discovery, graph mutation, utility, risk, and spreadsheet batch import, sharing pure `src/engine/*` modules.

## Tool Catalog Mapping

### [A. Discovery & Read Tools]
1. `list_workbooks()`: Returns workspace metadata and all workbooks with summary KPIs (`id`, `title`, `description`, `targetBudgetInr`, `placementsCount`, `branchesCount`, `fundingPct`, `pui`, `riskTier`).
2. `get_workbook_full({ workbookId })`: Returns full workbook JSON resolved with Entity names, computed Public Choice utility report, and Layer 1 structural risk report.
3. `search_entities({ query, includeCrossWorkspaceIndex? })`: Fuzzy searches `entities.json` (and optional device index) to prevent duplicate organizations.

### [B. Graph Mutation Tools]
4. `create_workbook({ title, description?, targetBudgetInr?, rootNgoName? })`: Creates new workbook JSON file with Root NGO anchored at Tier 0 (x: 400, y: 600).
5. `add_or_import_entity({ workbookId, name, category, globalNotes?, selectiveIncentives?, outreachAttempts?, importPendingYellowFromWorkbookId? })`: Deduplicates against `entities.json`, inserts non-overlapping placement, and optionally pulls confirmed yellow leads as dashed pending branches.
6. `update_placement_attributes({ workbookId, placementId, selectiveIncentives?, coOwnershipSignals?, outreachAttempts?, globalNotes? })`: Updates Public Choice attributes without touching coordinates.
7. `create_branch({ workbookId, sourcePlacementId, targetPlacementId, type, status, valuePct?, inKindValueInr?, note? })`: Validates no self-loops; enforces ownership rules; updates revision.
8. `update_branch({ workbookId, branchId, status?, type?, valuePct?, inKindValueInr?, note? })`: Toggles pending/tick/cross or updates values/notes cleanly.
9. `delete_branch({ workbookId, branchId })`: Removes branch cleanly.
10. `run_tidy_up_layout({ workbookId })`: Executes shared pure TypeScript `elkjs` (`direction: "UP"`) layout module on the workbook JSON and updates coordinates.

### [C. Public Choice Utility Tools]
11. `get_public_choice_utility_report({ workbookId })`: Returns exact PUI, Decision-Cost Efficiency, per-partner decomposition ($R_i, A_i, V_i, C_i, U_i, \eta_i, S_i$), and apathy warnings.
12. `update_utility_strategy_weights({ workbookId, alphaR, alphaA, alphaV, alphaC })`: Validates weights sum to 1.00 (within 0.001) and updates workbook.
13. `patch_workbook_metadata({ workbookId, title?, description?, targetBudgetInr?, status? })`: Edits workbook-level dashboard header settings and manifest.

### [D. Two-Layer Risk Tools]
14. `get_structural_risk_report({ workbookId })`: Executes Layer 1 (`src/engine/risk.ts`) and returns all 6 parameters, thresholds, overall tier, and offending IDs.
15. `write_risk_assessment_box({ workbookId, overallPosition, parameterCommentary, failureScenarios, publicChoiceDiagnosis, agentName })`: Populates or updates the persistent Layer 2 Risk Assessment Box displayed on the Maximized Dashboard.

### [E. Spreadsheet Interop Tools]
16. `export_workbook_spreadsheet({ workbookId, format, outputPath })`: Runs native deterministic exporter and writes CSV/XLSX directly to `outputPath`.
17. `batch_import_workflow_rows({ workbookId, rows, runTidyUpAfter? })`: Atomic batch ingestion: deduplicates entities, creates placements & branches respecting ownership rules, runs `elkjs` bottom-to-top layout, and returns summary.

### [MCP Resources]
- `partnership://workspace/overview` -> Active workspace & workbook list
- `partnership://workspace/entities` -> Full master `entities.json`
- `partnership://workbook/{id}/graph` -> Full workbook JSON
- `partnership://workbook/{id}/metrics` -> Live Funding + Utility + Risk JSON
