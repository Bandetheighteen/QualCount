# Plan 07-03: Production Agent Skills Installation (4 Complete SKILL.md Blueprints)

## Objective
Author and install the 4 production agent skills defined in Section 9 of the Master Architecture Specification into `.agent/skills/` (Antigravity), `.claude/skills/` (Claude Code), and `.cursor/skills/` (Cursor).

## Requirements Covered
- `SKILL-01`: Four production agent skills installed in `.agent/skills/`: `partnership-graph-operator`, `public-choice-utility-analyst`, `two-layer-risk-auditor`, and `spreadsheet-to-workflow-mapper`.

## Skills Detailed Specs

1. **`partnership-graph-operator`**:
   - Description: Operate the Partnership Ledger MCP server to build, edit, deduplicate, and tidy bottom-to-top multiplex NGO partnership workbooks cleanly without breaking ownership or measurement rules.
   - Enforces the 6 core domain rules: Always search before creating; strict three-color branch semantics; ownership separation rule; preserve declined memory (`status: "cross"`); no false confirmations; keep canvas clean (`run_tidy_up_layout`).

2. **`public-choice-utility-analyst`**:
   - Description: Analyze and update NGO partnership workbooks using Public Choice Theory (Buchanan & Tullock decision costs, Olson selective incentives, Niskanen bureaucratic utility, Ostrom credible commitments) via MCP without inventing arbitrary point scores.
   - Enforces strict prohibition against arbitrary 1-5 point scores; mandates 5-step analysis protocol: Olson/Niskanen incentive blindness, Ostrom credible commitments, Buchanan-Tullock efficiency $\eta_i$, Ostrom durability.

3. **`two-layer-risk-auditor`**:
   - Description: Execute a structured two-layer partnership risk audit combining deterministic graph risk metrics with qualitative institutional analysis, and publish the results to the Workbook's Risk Assessment Box via MCP.
   - Enforces 6 mandatory parameters review ($R_1..R_6$), qualitative context synthesis, concrete failure scenarios with trigger conditions and mitigations, and execution of `write_risk_assessment_box`.

4. **`spreadsheet-to-workflow-mapper`**:
   - Description: Parse messy real-world NGO Excel or CSV outreach spreadsheets and safely convert them into deduplicated bottom-to-top multiplex partnership workflows via the Partnership Ledger MCP server.
   - Enforces the 6 strict ingestion rules: read context first; prevent the 100-node canvas tangle; India-aware currency normalization; status mapping; referral chain detection; batch import and tidy.
