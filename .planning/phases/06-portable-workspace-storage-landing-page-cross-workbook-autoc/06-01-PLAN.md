# Plan 06-01: Portable Workspace Folder Architecture & Repository Adapters

## Objective
Implement the portable Workspace Folder storage specification (`workspace.json`, `entities.json`, `workbooks/wb_<id>.json`, `.snapshots/`), providing serializers, parsers, and a unified `FolderWorkspaceRepository` that functions identically across browser dev sessions, Tauri native file access, and Google Drive syncing.

## Requirements
- `STOR-04`: Storage abstraction (`WorkspaceRepository`) supports portable Workspace Folders on disk and cloud storage containing `workspace.json`, `entities.json`, `workbooks/*.json`, and local `.snapshots/`.
