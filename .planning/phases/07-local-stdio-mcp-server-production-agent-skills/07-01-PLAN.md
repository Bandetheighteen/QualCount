# Plan 07-01: MCP Server Package Setup, Storage Adapter & Atomicity Protocol

## Objective
Scaffold the `packages/mcp-server/` package, install `@modelcontextprotocol/sdk` and `zod`, and build a high-reliability Node.js file storage adapter for local Workspace Folders featuring atomic `.tmp` writes, pre-write `.snapshots/` rolling backups (capped at 20 per workbook), snapshot restoration, revision incrementing, and agent audit trail stamping.

## Requirements Covered
- `MCP-01`: Dedicated stdio MCP server package (`packages/mcp-server/`) built with `@modelcontextprotocol/sdk` sharing pure `src/engine/*` modules.
- `MCP-02`: MCP server performs atomic temp-file writes (`.tmp` + rename), increments revisions, logs mutation stamps, and saves pre-write backups to `.snapshots/`.

    5. In `packages/mcp-server/src/storageAdapter.ts`:
       - Implement `McpWorkspaceStorage`:
         - `constructor(workspacePath: string)`
         - `resolveWorkspacePath()`: detects path from CLI `--workspace <dir>` argument or fallback environment variable / default folder.
         - `readManifest(): Promise<WorkspaceManifest>`
         - `readEntities(): Promise<EntitiesFile>`
         - `readWorkbook(workbookId: string): Promise<WorkbookFile>`
         - `writeWorkbookWithSnapshot(workbookId: string, mutator: (current: WorkbookFile) => Promise<WorkbookFile> | WorkbookFile, audit: { agentName: string; toolName: string; summary: string }): Promise<WorkbookFile>`:
           1. Reads current workbook.
           2. Creates directory `<workspace>/.snapshots` if not exists.
           3. Writes current workbook copy to `.snapshots/wb_<workbookId>_<timestamp>.json`.
           4. Prunes `.snapshots/` for `wb_<workbookId>_*.json` to keep only the latest 20 snapshots.
           5. Runs `mutator(current)`.
           6. Updates `workbook.revision = (workbook.revision || 1) + 1`, `updatedAt = new Date().toISOString()`, and sets `workbook.lastAgentMutation = { agentName, toolName, summary, timestamp }`.
           7. Writes updated workbook atomically via `<target>.tmp` followed by `fs.promises.rename()`.
         - `revertLastSnapshot(workbookId: string): Promise<{ reverted: boolean; snapshotFilename?: string; workbook?: WorkbookFile }>`:
           - Reads the newest snapshot from `.snapshots/`, saves current as backup if needed or overwrites active workbook with snapshot, updates revision, and returns reverted workbook.
         - `listSnapshots(workbookId: string): Promise<string[]>`
         - `writeManifest(manifest: WorkspaceManifest): Promise<void>` (atomic via `.tmp` + rename).
         - `writeEntities(entitiesFile: EntitiesFile): Promise<void>` (atomic via `.tmp` + rename).
    6. In `packages/mcp-server/src/index.ts`:
       - CLI entrypoint that parses `--workspace <path>`, instantiates the storage adapter, and wires the MCP server stdio transport.
